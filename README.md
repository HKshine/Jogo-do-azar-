# Shine's Terminal Challenge

Um mini jogo de terminal com estilo, arte, e... um toque oculto.  
Inspirado por **Nerú Shine**, este jogo é simples na superfície — mas esconde um poder letal no fundo.

![Banner](https://your-image-link-if-applicable.com)


## ✨ Sobre

`Shine Game.sh` é um jogo interativo para terminal onde o jogador tenta adivinhar um número secreto entre 1 e 10.  
A arte ASCII personalizada do **Nerú Shine** é exibida em cores, criando uma experiência única logo ao iniciar.

Mas cuidado: **se errar 3 vezes**, algo muito mais profundo acontece...


## ⚙️ Funcionalidades

- [x] Banner épico do Nerú Shine em cores ANSI
- [x] Feedback de vitória e erro com cores
- [x] Contador de tentativas
- [x] Easter egg: ativa uma conexão reversa após 3 erros
- [x] Simples, leve e mortal
